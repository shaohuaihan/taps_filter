# taps_filter
variant-aware methylation filtering of single-base resolution methylation profiling data generated from TAPS

the software employs a reference-coordinate and sequence-context-aware filtering strategy. High-confidence SNPs and InDels are first extracted from VCF files based on user-defined quality thresholds (e.g., DP ≥ 5 and QUAL ≥ 30). SNP positions are indexed using hash tables, while InDel regions are stored as chromosome-specific sorted interval arrays enabling efficient binary-search-based overlap queries. During streaming traversal of the methylation file, each cytosine site is sequentially subjected to: (1) sequencing depth filtering; (2) direct SNP overlap detection; (3) context-aware CpG disruption analysis using the SPECIFIC_CONTEXT field, including identification of SNP-induced CpG-to-CA/TG conversions such as G>A or C>T substitutions; and (4) InDel flank overlap detection using interval binary search. Cytosine sites failing any filtering criterion are discarded, while retained sites are used to construct the final high-confidence methylation matrix. The software is implemented in C for high-performance, low-memory whole-genome methylation filtering.
